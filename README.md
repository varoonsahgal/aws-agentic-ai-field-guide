# Agentic AI Field Guide

Student study guide for the **AWS Agentic AI Demonstrated** micro-credential (Skill Builder exam lab): the six challenges explained, with diagrams, traps, drills, a crib sheet and a glossary. Companion to the OrbitOps break-fix practice labs.

Published with GitHub Pages from this repository root: open `index.html`, or the Pages URL in the repository settings.

AWS documentation diagrams are reproduced from docs.aws.amazon.com with attribution in their captions; service icons are from the AWS Architecture Icons set.
